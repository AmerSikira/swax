## What to build

Define how projects acquire trustworthy GA4, GSC, and page evidence.

Decision or verification prerequisite for the product slices.

## Acceptance criteria

- [ ] Verify authentication, consent scopes, property/site selection, refresh/reconnect behavior, quotas, and supported reporting dimensions using primary provider documentation.
- [ ] Define public page discovery/capture, supported content formats, manual-content provenance, source-period/time-zone semantics, and explicit freshness/availability states.
- [ ] Define safe public fetch boundaries, redirect/size/time limits, and prevention of fetching private network resources; make inaccessible pages recoverable through manual content.
- [ ] Specify deterministic adapter examples and integration checks needing real credentials; expose unresolved access requirements instead of assuming live connections exist.
- [ ] Record reviewed policies and completion evidence before closing the gate.

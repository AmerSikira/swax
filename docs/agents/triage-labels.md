# Triage labels

| Role            | GitHub label    | Meaning                               |
| --------------- | --------------- | ------------------------------------- |
| needs-triage    | needs-triage    | Maintainer evaluation needed          |
| needs-info      | needs-info      | Missing information                   |
| ready-for-agent | ready-for-agent | Work is specified; honor its blockers |
| ready-for-human | ready-for-human | Human implementation required         |
| wontfix         | wontfix         | Work will not be undertaken           |

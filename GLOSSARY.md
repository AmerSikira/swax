# Website Improvement

The language used to discuss website improvements and their outcomes.

## Language

**Tenant**:
A customer organization whose projects and associated data share an ownership scope.
_Avoid_: Project, user

**Team owner**:
The owner and administrator of a tenant, who manages the AI key used for the team's projects.
_Avoid_: Project owner, regular user

**Project**:
One website and its associated pages, data connections, goals, recommendations, and change history.
_Avoid_: Page, data source

**Website**:
The site whose pages and visitor behavior are being analyzed for improvement.
_Avoid_: Property

**Goal**:
A desired website outcome against which a project's recommendations and implemented changes are evaluated.
_Avoid_: Recommendation, metric

**Signup**:
Completed account creation on the website being evaluated.
_Avoid_: Signup-button click, signup-page visit

**Recommendation**:
A proposed website change intended to improve a defined outcome, informed by available website data.
_Avoid_: Fix, instruction

**Analysis**:
A review of a project's available evidence and context that produces improvement ideas.
_Avoid_: Evaluation

**Analysis run**:
An analysis performed at a particular time using a particular set of project evidence and context.
_Avoid_: Evaluation

**Evidence**:
Measurements and website content that support a recommendation or evaluation.
_Avoid_: Recommendation, hypothesis

**AI review**:
An AI interpretation of project measurements or evaluation data requested by a user.
_Avoid_: Calculated metric, evaluation outcome

**Implemented change**:
One or more website modifications that the website operator has put into effect together.
_Avoid_: Recommendation, automatic optimization

**Change record**:
A record of an implemented change and its go-live date, optionally linked to one or more recommendations.
_Avoid_: Recommendation, evaluation

**Evaluation**:
An assessment of results after an implemented change against a defined project goal.
_Avoid_: Analysis, recommendation status

**Project history**:
A persistent record of a project's earlier analyses, recommendations, decisions, implemented changes, and results.
_Avoid_: Chat history, model memory

**Project brief**:
An editable description of a website's audience, offering, goals, and business constraints.
_Avoid_: Analysis, project history
